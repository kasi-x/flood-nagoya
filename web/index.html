このエミュレーターについて

降雨が地表・街を流れる様子を、実標高 (国土地理院 数値標高モデル5m) と PLATEAU建物 (約74万棟を流路障害物化) を用いたGPU浅水方程式で計算します。 下水道の排水は「排水能力」として近似しており、行政のハザードマップではありません。

出典: 国土地理院 dem5a・航空写真(ort) / Project PLATEAU (2022 名古屋市)
